# Excel

Vue 2.7 + Vuetify 2.7 프로젝트입니다.

## 실행

```sh
npm install
npm run serve
```

## 배포용 빌드

```sh
npm run build
```

코드는 공백 4칸으로 들여쓰기하며, Vuetify 컴포넌트와 스타일 유틸리티를 우선 사용합니다.

## 스캔 배치

1. 4·6·8칸 중 시트를 선택합니다.
2. 이미지 업로드 버튼으로 TIFF, PNG, JPG, WEBP 파일을 선택합니다. 어느 시트에서 업로드해도 모든 시트의 같은 순번에 반영됩니다.
3. 미리보기에서 순서를 확인하고 필요하면 이동하거나 삭제합니다. 칸을 클릭해 이미지를 교체하거나 다음 빈 칸에 추가할 수 있습니다. 변경과 삭제는 모든 시트에 반영됩니다.
4. 상단의 **4칸/6칸/8칸 인쇄** 버튼을 누르면 선택한 배치의 모든 페이지를 브라우저에서 바로 인쇄합니다.
   인쇄 창에서 A4 세로, 배율 100%를 사용하고 머리글/바닥글은 끕니다.

이미지 목록의 **텍스트 배치** 버튼에서 이미지마다 여러 텍스트를 추가할 수 있습니다.
내용, 크기, 색상, 굵기를 설정하고 글씨를 드래그하거나 이미지의 원하는 위치를 클릭해 배치합니다.
배치 적용을 누르면 이미지에 글씨가 합성되어 미리보기와 인쇄에 포함됩니다.
텍스트를 모두 삭제하고 적용하면 원본 이미지로 돌아갑니다. 이미지 이동 시 텍스트도 함께 이동하며 이미지 교체 시 초기화됩니다.
화면 전체는 스크롤하지 않고 목록과 미리보기만 내부 스크롤을 사용합니다. 각 미리보기 페이지는 가용 화면 높이에 맞춰 표시됩니다.
이미지 초기화 버튼을 누르면 확인 다이얼로그가 열립니다. 취소하면 이미지를 유지하며 초기화를 선택하면 이미지와 텍스트를 모두 삭제합니다.

4·6·8칸은 원본 양식과 동일한 2열×2행, 2열×3행, 2열×4행으로 배치합니다.
페이지마다 A4 한 장에 출력하며 칸 수를 넘으면 다음 인쇄 페이지로 이어집니다.
출력에는 이미지와 커스텀 텍스트만 포함되며 버튼, 목록, 빈 칸 번호는 제외됩니다.
이미지는 여백 없이 각 칸의 가로·세로 크기에 맞춰 채웁니다. 원본 비율은 달라질 수 있으며, TIFF는 페이지별로 분리합니다.
이미지는 브라우저에서 처리하며 새로고침하면 업로드 목록이 초기화됩니다.
파일 용량 제한은 없으며 목록에 원본 파일 용량과 해상도를 표시합니다.
여러 페이지 TIFF는 각 페이지에 원본 TIFF 전체 파일 용량을 표시합니다.
이미지당 4천만 픽셀 해상도 제한은 유지합니다.

```sh
npm run verify:layout
```

## GitHub Pages

저장소 Settings → Pages → Build and deployment → Source를 GitHub Actions로 설정합니다.
main 브랜치에 코드를 푸시하면 검증과 빌드 후 GitHub Pages에 자동 배포됩니다.
저장소 이름 아래 경로에서도 동작하도록 배포 파일은 상대 경로를 사용합니다.
